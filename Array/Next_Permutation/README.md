# GFG Next Permutation

## Problem

Given an array `arr`, rearrange it to the next lexicographically greater permutation. If no such permutation exists, rearrange to the smallest (sorted ascending).

## Approach

Standard next permutation: find pivot, swap with successor, reverse suffix.

## Complexity

O(n) time, O(1) space.
