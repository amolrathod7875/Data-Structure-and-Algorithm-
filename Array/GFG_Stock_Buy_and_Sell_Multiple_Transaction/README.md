# GFG Stock Buy and Sell – Multiple Transaction Allowed

## Problem

Maximize profit with multiple buy/sell transactions (buy before sell, no overlapping).

## Approach

Sum all positive adjacent price differences.

## Complexity

O(n) time, O(1) space.
